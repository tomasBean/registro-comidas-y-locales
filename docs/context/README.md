# Notas de contexto

Índice de notas cortas y enlazadas. Una idea por archivo. Al terminar una parte del trabajo, volcá acá lo importante en lugar de dejarlo en la conversación.

Convenciones:
- Un tema por archivo, nombre en minúsculas con guiones (`modelo-de-datos.md`).
- Enlazá entre notas con links relativos (`[modelo de datos](modelo-de-datos.md)`).
- Cada nota abre con una línea que dice de qué trata y cuándo se actualizó.
