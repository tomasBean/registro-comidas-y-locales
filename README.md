# Libreta de comidas

App personal para registrar los lugares donde comemos y qué pedimos en cada visita (puntaje, precio, comentario, foto), con mapa, lista de "quiero ir" y ranking propio.

**Estado:** en preparación. Todavía no hay código; ver `PROGRESS.md`.
